        Welcome to Caddi
        
        
        The Caddie for your coding agents.
        
        
        Keep every project in its own workspace, let agents in only where you approve, and point at exactly what should change.
        
        
        
          
        
            Open source, MIT licensed
            Read every line, change anything, and star the project if it is useful to you.
          
        
          
        
        
        
        
      
        
      
        
        
        Workspaces
        
        
        Name your first workspace
        
        
        A workspace is a separate browser profile for one project, with its own tabs, sign-ins and history. An agent only ever sees the workspace you share with it.
        
        
        
        
        
        Keep the name as it is if you like. Add more workspaces from the rail on the left at any time.
        
      
        
      
        
        
        Agents
        
        
        Connect your coding agent
        
        
        Caddi found these coding tools on this Mac. Connecting adds Caddi to that tool’s settings. Nothing can see a page until you approve it on screen.
        
        
        
          
          
        
          
        
          
        
          
      
          
      
          
        
          Annotate
          
        
          Point at what should change
          
        
          Open any page, turn on Annotate, click the thing and write a note. Your agent gets the element, where it lives in the code, and your words. The count next to Annotate shows what you sent and whether the agent received it.

            Site permissions
            
      
    
            
    
            
      
            Check which site is asking, and for what, before you allow it.
            
      
            
      
            
        
            Camera and microphone
            
        
            
        
            
        
            Revoking blocks new requests. It may not stop a stream that is already running. “End page activity” closes that page, after asking about unsaved work.
            
        
            
      
            
      
            
        
            Pop-up windows
            
        
            Allow one pop-up, then try again on the page within 30 seconds. Blocked form submissions are not retried for you.

            Recent activity
            
        
            
      
            
      
            
        What is supported?
        
            This development build can ask you about notifications, camera and microphone. Screen sharing and other site permissions are not available yet. Video-call sites have not been fully tested.

Caddi has no account, and nothing syncs to other devices.
